# 📖 설정집 — 미래의 나와 은하제까지 14일

모든 대본 작가가 이 문서를 따른다. 대본은 **JSON 파일**이며 `python tools/check_story.py <파일이름>` 검사를 통과해야 한다.

## 1. 장르 · 톤
- 일본 미연시(미소녀 연애 시뮬레이션) 느낌의 **학원 러브코미디 + 잔잔한 감동**.
- **전연령 · 건전**: 신체 묘사, 성적 암시, 노출, 음주·흡연 금지. 스킨십은 손잡기, 머리 쓰다듬기, 어깨에 기대기까지만. 고백은 엔딩에서.
- 비극 금지: 죽음, 큰 사고, 자해 없음. 고민은 진로, 외로움, 부상, 이별(전학/유학) 같은 현실적인 것으로 하고, 결말은 희망적으로.
- **완전 창작**: 기존 애니·만화·게임·드라마의 캐릭터 이름, 설정, 명대사, 노래 가사를 쓰지 않는다. 특정 작품 패러디도 하지 않는다.
- 한국어. 자연스러운 구어체. 대사 한 줄은 **80자 이하**(권장 25~55자). 긴 말은 여러 줄로 나눈다.

## 2. 무대
- **사립 은하고등학교**. 2학기 시작부터 학교 축제 **「은하제」**까지 14일. 축제 준비 기간이라 주말에도 학교에 나온다.
- 하루는 1~5교시. 플레이어는 교실, 도서관, 급식실, 운동장, 보건실, 복도를 오간다.
- 은하제 마지막 밤에는 운동장에서 **불꽃놀이**가 있다. "불꽃놀이 때 함께 있던 사람과 이어진다"는 학교 전설이 있다. 엔딩 고백 장면의 무대다.

## 3. 인물

### 주인공 — `me`
- 2학년 남학생. 이름은 플레이어가 정한다. 다른 인물이 부를 때는 **`{name}`** 이라고 쓴다 (예: `"{name}, 늦었잖아!"`).
- 착하고 눈치가 빠르지만 우유부단하다. 중요한 순간에 말을 삼키는 버릇이 있다. 혼잣말이나 속마음은 괄호로 쓴다: `"(…심장이 왜 이렇게 뛰지.)"`

### 미래의 나 — `future`
- 10년 뒤의 주인공, 27세 회사원. 할아버지가 남긴 **낡은 회중시계**를 통해 과거로 왔다.
- 후회: "10년 전 은하제 불꽃놀이 날, 좋아하는 사람에게 마음을 전하지 못했다." **그 사람이 누구인지는 끝까지 밝히지 않는다** (플레이어가 고른 히로인이 곧 답이 되도록).
- 다정하고, 썰렁한 아재개그를 하고, 가끔 쓸쓸한 얼굴을 한다. 주인공을 "나"라고 부르거나 "너"라고 부른다.
- **돌발 상황 (게임 규칙)**: 매일 3교시가 되면 회중시계가 오작동해 주인공과 미래의 나의 **역할이 바뀐다**. 3교시 동안은 플레이어가 미래의 나가 되어 움직인다. 히로인과 연애 이벤트는 할 수 없고, 어른의 눈으로 힌트를 얻는다. 4교시가 되면 원래대로 돌아온다. 다른 사람들 눈에는 "주인공을 닮은 수상한 어른"으로 보인다.

### 조연
- `doyun` **도윤**: 주인공의 절친. 급식왕, 학교 정보통. 유쾌하고 눈치가 없지만 의리가 있다. 연애 상담 담당.
- `kim` **김 선생님**: 담임, 국어 선생님. 엄하지만 따뜻하다. "흠흠."
- `han` **한 선생님**: 보건 선생님. 상냥하고, 학생들의 고민을 들어 준다.
- `narr`: 지문(나레이션). `expr` 없이 쓴다. 예: `{"who":"narr","text":"창밖으로 빗소리가 들렸다."}`

## 4. 표정 (`expr`)
`normal` 보통 · `happy` 웃음 · `surprised` 놀람 · `tired` 지침/곤란 · `angry` 화남/삐짐 · `blush` 부끄러움 · `sad` 슬픔

## 5. 배경 (`bg`)
`classroom` 교실 · `library` 도서관 · `cafeteria` 급식실 · `field` 운동장 · `infirmary` 보건실 · `hallway` 복도 · `rooftop` 옥상 · `sunset` 노을 진 하굣길 · `night` 밤 학교 · `festival` 축제 · `rain` 비 오는 창가

## 6. 히로인 파일 형식 — `web/static/story/<id>.json`
```json
{
  "id": "seorin",
  "name": "한서린",
  "short": "서린",
  "title": "도서부 · 쿨데레",
  "profile": "프로필 2~3문장 (호감도 수첩에 표시됨)",
  "likes": "성적",
  "schedule": ["도서관", "교실", "도서관", "급식실", "도서관"],
  "chat": [ [ 대사, 대사, ... ], ... ],
  "hints": [ [ 대사, ... ], ... ],
  "events": [ 이벤트 12개 ],
  "ending": { "title": "...", "bg": "festival", "lines": [ 대사 40줄 이상 ] }
}
```
- `likes`: 히로인이 중요하게 여기는 능력치 (`체력`/`성적`/`우정`). 일부 이벤트의 `need` 조건에 쓴다.
- `schedule`: 1~5교시에 히로인이 있는 장소. 3교시에는 플레이어가 미래의 나다.
- `chat`: **잡담 12개 이상**. 각 2~5줄, 선택지 없음. 이벤트가 없을 때 말을 걸면 하나가 나온다. 주인공(`me`)과 주고받는 짧은 대화.
- `hints`: **힌트 대화 6개 이상**. 각 2~5줄. 3교시에 **미래의 나(`future`)**가 히로인에게 말을 거는 장면이다. 히로인은 "수상한 어른"에게 반응하고 (시온만 눈치챈다), 미래의 나는 속마음(괄호)이나 말로 공략 힌트를 준다. 예: 그녀가 좋아하는 것, 필요한 능력치, 다음에 어디로 가면 좋을지.
- **대사 하나** = `{"who": "seorin", "expr": "blush", "text": "…착각하지 마."}`
- **선택지** = 대사 목록 안에 `{"choice": [ 선택 2~3개 ]}` 를 넣는다.
  선택 하나 = `{"text": "버튼 글자(40자 이하)", "aff": 5, "lines": [ 그 선택 후 대사들 ] }`
  `aff`: 호감도 변화 −3~6. 최선 +4~6, 무난 +1~2, 실수 −1~−3. 선택지 안에 선택지를 넣으면 안 된다. 선택지가 끝나면 다음 대사로 이어진다.

### 이벤트 12개 (`events`) — 고정 값
| 순서 | id | min_day | min_aff | need |
|---|---|---|---|---|
| 1 | `<id>_01` | 1 | 0 | 없음 (첫 만남) |
| 2 | `<id>_02` | 1 | 3 | |
| 3 | `<id>_03` | 2 | 6 | |
| 4 | `<id>_04` | 3 | 10 | |
| 5 | `<id>_05` | 4 | 14 | |
| 6 | `<id>_06` | 5 | 19 | `{ "<likes>": 55 }` |
| 7 | `<id>_07` | 6 | 24 | |
| 8 | `<id>_08` | 7 | 29 | |
| 9 | `<id>_09` | 8 | 34 | `{ "<likes>": 62 }` |
| 10 | `<id>_10` | 9 | 39 | |
| 11 | `<id>_11` | 10 | 44 | |
| 12 | `<id>_12` | 11 | 50 | `{ "<likes>": 68 }` |

이벤트 하나 = `{"id","title","min_day","min_aff","need"(선택),"bg","lines"}`
- **대사 30줄 이상** (선택지 안의 대사 포함), **선택지 1~2개**.
- 12개가 하나의 이야기다: 첫 만남 → 가까워짐 → 비밀 발견 → 갈등/위기 (8~10) → 극복 → 축제 직전의 약속 (12).
- 미래의 나가 이벤트에 가끔 나와도 된다 (멀리서 지켜보거나, 끝난 뒤 한마디).

### 엔딩 (`ending`)
- 은하제 밤, 불꽃놀이 아래 고백 장면. **40줄 이상**, 선택지 없음.
- 마지막 부분에 **미래의 나와의 작별** 장면이 들어간다: 회중시계가 멈추고, 미래의 나가 "이번엔 말했구나"라며 웃으며 사라진다.
- 마지막 줄은 `narr` 로 여운을 남긴다.
